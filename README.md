# Axle Lock Detection in Locomotives

An end-to-end Machine Learning pipeline to detect and prevent locomotive axle lock anomalies using multi-sensor telemetry data.

---

## Features
* **FastAPI Backend:** High-performance REST API for real-time predictions.
* **ML Anomaly Detection:** Processes speed, temperature, and vibration telemetry.
* **Web UI:** Interactive `frontend.html` interface to send test inputs.
